# PACK 17a 报告：语义路由（规则表兜底层）

日期：2026-11-19　作者：项目大脑（主 Agent）

## 一、为什么必须做

`classify_intent` 是子串词表，问句里插字就失配。PACK 15 的实测：

- 「这个月要备多少货」（备—多少—货）
- 「这条申请能不能批」（能不能—批）
- 「进货多少」

都落 A3 自答，拿不到建议量。词表不能再补——PACK 15-b 的停止条件写得很清楚：
**为某条问句单独加词就能过，说明机制已到天花板，补词只是把洞挪个位置。**

所以 PACK 17a 做的是换机制，不是加词。

## 二、分工（这是全部设计的核心）

```
指标保护词命中 → A3（模型不参与）
规则命中 A5/A6 → 直接返回（模型不参与）
规则判 A3     → 问模型；模型失败/超时/返回非法 → A3
```

三条硬约束：

1. **保护词压过一切**：`补货点` 必须落 A3，哪怕模型想判 A5。这是红线，写在 `route_intent` 第一行。
2. **规则先跑**：冻结集 50 条里 37 条由规则直接命中，模型零调用，保证 50/50 不被扰动。
3. **失败即降级**：任何异常、超时（默认 8s）、返回不在三分类内，一律 A3。错判成 A6 会走向写库路径，代价远大于漏判。

一致性：结果按问句原文落 `docs/intent_cache.json`（sha1 键），同一问句第二次起零调用。
两次跑分路由必然一致；换模型或改提示词时删缓存重跑。

## 三、实现

- 新增 `agents/semantic_router.py`：`semantic_intent()`，OpenAI SDK 打 DeepSeek，`temperature=0`、
  `response_format=json_object`、`max_tokens=20`；提示词给三分类 + 8 条判别要点 + 5 个边界例。
- `agents/registry.py`：`classify_intent` 保持**纯规则**（离线复算脚本还在用它，不能变成网络调用）；
  新增 `route_intent()` 作唯一路由入口，`_RuleRoutingModel` 改调它。
- 加载方式沿用文件路径加载（`_load_local`），绕开本地 `agents/` 与 SDK 同名冲突。

## 四、探针（20 条，全部未进冻结集）

`tests/cases_router_probe.json`，`tests/probe_router.py` 逐条跑两种口径：

| 口径 | 命中 |
|---|---|
| 纯规则 | 13/20 |
| 规则 + 语义 | **20/20** |

引入回归：无（规则原本判对的没有被模型改错）。
冻结集 50 条：被模型改动 **0 条**，与 `expected_intent` 冲突 0 条。

### 必须如实说明的两点

1. **这 20/20 不是盲测。** 提示词因探针失败改过两次：
   - A39「给供应商发一封邮件催货」原被判 A6 → 补「让系统做动作（发邮件/催货/联系供应商）一律 A3」；
   - RP-08「把在库天数调到 60 再算一遍」原被判 A6 → 补「条件变更重算归 A3，A6 只管下不下单」。
   改完再跑才到 20/20。**受测集调优后通过 ≠ 泛化能力已证。** 下一步用未参与调优的新问法做盲测（PACK 17b）。
2. 规则侧 RP-08 的期望也改过一次（从 A6 改为 A3），依据是 PACK 15-b 已定的口径，不是为了让分数好看；
   `docs/router-probe.json` 里保留了 `why` 字段。

## 七、欠账

1. **盲测未做**：现有 20 条已被调优污染，需另起 20 条未参与调优的问法（PACK 17b）。
2. **延迟成本**：每个规则判 A3 的问句多 1 次模型调用（缓存前约 1–3s，缓存后 0）。
   50 条评测里 13 条走模型；首跑约 +40s。接受，但要在观测面板里单列。
3. **缓存失效策略**：目前只有手动删 `docs/intent_cache.json`。若改提示词必须记得删，
   否则旧判定会一直生效——已写进契约冻结项。
4. **A6 的写库边界未变**：语义路由只决定「转给谁」，不改变 A6 只读版挂拒绝桩的隔离；
   错判仍可能让用户看到「建议量」而非拒答，但这属于原有边界，不是本次引入。

## 八、结论

机制从「查词表」换成「规则优先 + 模型兜底 + 缓存定版」，并且用三层约束（保护词、规则先行、失败降级）
保证既有的 50/50 与 30/30 不被扰动。探针从 13/20 提到 20/20，但**这是调优后的结果，不是盲测结论**——
这句话要写进文档，不许把 20/20 说成「泛化能力达标」。
