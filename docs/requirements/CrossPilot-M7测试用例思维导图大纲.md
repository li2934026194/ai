# M7 内容创作与合规交付测试用例

## 冒烟测试用例 (12)
### M7-1 多语言商品文案全流程
- 1.待办承接与选品
  - 读取 M4-3 已批准新品（SKU-00704）
  - 读取在售老品翻新（BAG-108）
  - 上游接力条带入 M0-2 规格与 M1-2 FAQ
- 2.平台、语言与三层词库配置
  - 平台：亚马逊美国站（200字符）/ 虾皮泰国站（120字符）/ TikTok 美区（150字符）
  - 品牌必用词（快捷芯片追加 + 去重）
  - 平台红线库 + 商标侵权词 + 监管敏感词
- 3.生成多版本文案草稿
  - 成功
    - 返回 3 组差异化草稿（热搜词版/卖点版/场景版）
    - 中英双语对照开关正常切换
    - 必用词绿底高亮，违禁词红底拦截
  - 失败
    - 生成服务异常/空返回提示重试
- 4.写入交付清单与就地微调
  - 一键采纳 4 类核心文案（4/4）
  - 含违禁/商标/监管/超长草稿点击写入 → 强拦截并写审计
  - 合规文案就地编辑微调
    - 输入实时重扫（必用词/红线词/字节数/ALL CAPS）
    - 保存
      - 成功 → 更新清单并标「已人工微调」
      - 失败 → 阻断保存（空文本/红线词/超长）并在线修改再提交
    - 还原 AI 原稿 → 无损恢复初始稿
- 5.前端展示
  - 核心 4 类 + 扩展 6 类（8+N）页签切换无串位
  - 后台属性说明联动 M0-2 完整字段

### M7-2 主图与详情套图全流程
- 1.上游接力与主体锁定
  - 同步 M7-1 核心卖点开关（开/关验证）
  - 锁定实物 SKU 主体与配件数量（防竞品多件套幻觉）
- 2.结构化工作台配置
  - 工作流模板（标准白底 / 欧美居家场景）
  - 视觉风格 + 机位视角 + 画幅比例（1:1 / 3:4 / 4:5）
  - 负向避坑约束芯片开关
  - 5 个图位独立设计要求编辑与恢复推荐文案
- 3.提交 1+4 异步生成任务
  - 提交
    - 成功 → 调度 GPU 节点并记录 prompt_id
    - 失败 → 节点不可用/幂等重复提交提示
  - 轮询与入库
    - 成功 → 校验 image/* MIME 后入库，5/5 出图（标「演示图」）
    - 失败 → 无输出/node error/MIME 不匹配 → 标失败不伪造 5/5
- 4.局部修正闭环
  - 仅重绘当前图位 → 仅更新选中图位，其余 4 张不变
  - 局部修改对比弹窗 → 修改前后对比
    - 指令为空 → 拦截提示
    - 指令合法 → 仅更新选中图位，写入审计
- 5.AI 人物元数据合规校验
  - 勾选含 AI 合成人物出镜
  - ComfyUI_EU_AI_Label 末端节点写入双字段（trainedAlgorithmicMedia + contains-synthetic-performer）
  - 模拟裁剪转码丢失 → 标红阻断上架
  - 重新写入并读回校验 → 恢复绿灯通过

### M7-3 商品短视频与 A+ 全流程
- 1.上游接力与配置
  - 联动 M7-2 套图（X/5）与 M7-1 文案
  - 4 种脚本风格 + 配音音色 + 背景音乐
- 2.生成 15s 短视频
  - 未配置视频生成节点 → 如实失败阻断，不产出空文件，保留已有图文
  - 已配置节点 → 生成 3 段分镜成片，可播放/暂停/进度跳转
- 3.3 段分镜卡片编辑与重做
  - 切换关联 M7-2 图位（1~5）+ 切换运镜（微距慢推/平滑横移/稳态展示/轻缓拉远）
  - 直接修改 EN/CN 字幕 → 播放器字幕与素材溯源列表实时同步
  - 引用 M7-1 文案
    - 已选标题/五点 → 一键填充并跳转预览
    - 未选定 M7-1 → 明确报错拦截，保留原分镜脚本
  - 重做本镜 → 仅刷新单镜与日志，其余 2 镜不变
- 4.生成可视化 A+ 图文长页
  - 自动组装品牌横幅 + 场景/性能模块 + 规格对比表
  - 交付进度同步更新至 8/8

### M7-4 合规检查与成品打包全流程
- 1.规则矩阵与资质核验
  - 切换站点（Amazon/Shopee/TikTok）× 类目（厨房/箱包/3C/美妆）→ 实时刷新规则版本与认证要求
  - TikTok 美区展示保证金与违规扣分监测
  - 资质有效期管理
    - 模拟过期 → 标红阻断
    - 续期恢复 → 恢复有效
- 2.6 页签成品总览与 8+N 缺项补齐
  - 买家视角预览：固定「预览，尚未发布」横幅、5 图切换、折扣计算、变体切换、9 项属性
  - 8 类主清单缺项点击一键跳转 M7-1/2/3 或补齐 A+
  - 8+N 扩展清单独立计数（0/6~6/6）点击直达对应 M7-1 页签
- 3.运行 5 项上架合规检查
  - 广告违禁词 + 标题字数 + IPTC/XMP + 资质有效期 + 8/8 完整度
  - 不通过 → 保存检查记录、展示明细、退回创作人待办补齐再提交
  - 通过 → 保存独立 ComplianceCheck 记录、待办流转至主管（approver）
- 4.主管审批门禁与离线导出
  - creator 尝试自批/导出 → 按钮禁用/接口 403 拦截并写审计
  - approver 审核不通过 → 填写意见驳回并通知创作人返工
  - approver 审核通过
    - 意见为空 → 拦截提示
    - 意见合法 → 保存审批人/时间、解锁导出、下载离线 HTML 交付包并记审计

## 其他测试用例 (106)
### 1. 功能边界与等价类 (24)
- 平台字符边界
  - Shopee：119 / 120 / 121 字符
  - TikTok：149 / 150 / 151 字符
  - Amazon：199 / 200 / 201 字符
- UTF-8 字节边界（后台搜索词）
  - 纯 ASCII 249 / 250 / 251 bytes
  - 含多字节符号（® / — / 中文）精确计算 bytes
- ALL CAPS 软提示边界
  - 标准缩写白名单（USBC / BPA / HDMI / LED）不误报
  - 4 位及以上全大写（AMAZING / SAVE）黄色提示但不强拦截
- 价格与折扣边界（买家视角）
  - 正常折扣（售价 $24.9 / 划线价 $39.9 → -38% OFF）
  - 无划线价或售价 ≥ 划线价（不显示负折扣）
  - M0-2 缺失字段显示「待补（去 M0-2）」不报 NaN/undefined
- 资质日期边界
  - 昨天过期（T-1）→ 阻断
  - 当天到期（T）/ 明天到期（T+1）→ 有效/临期提醒
- 多品类混合批量样本（10 SKU）
  - 3 厨房小电 + 3 3C 配件 + 2 箱包 + 2 美妆（混入 2 条失败项）

### 4. 兼容性测试 (6)
- 浏览器：Chrome / Edge / Firefox / macOS Safari
- 分辨率：1920×1080 / 1440×900 / 1280×800 / 1024×768（响应式降列）
- 多语言混合：EN + 简体中文 + 泰文（อย.）+ 符号（®™°×）
- 正则元字符输入（C++ / 2.4G / #1 / [Pro]）不崩溃
- 离线 HTML 导包跨 OS 断网打开完整渲染
- 无 createObjectURL 受限环境安全判空

### 5. 性能测试 (6)
- 28 页 × 9 岗位切换单次 rerender < 50ms
- 编辑框 500 字符实时扫描 < 10ms 无掉帧
- 单 SKU 出图 P95 ≤ 30 秒（联调 GPU 基准）
- 多 SKU 批量吞吐 ≥ 100 SKU/小时/GPU
- 15s 视频预览定时器切换销毁无内存泄漏
- 离线 HTML 导包生成耗时 < 1 秒

### 6. 安全与权限测试 (8)
- 9 岗位 RBAC 矩阵逐一校验（只读岗位全禁用）
- creator 绕过 DOM 强行调用主管批准 → 403 拦截 + 审计
- 跨组织越权操作拦截（403/404）+ 审计
- 存储型/反射型 XSS 注入（文案/要求/字幕/审批意见/导包 HTML 转义）
- 违禁词库防前端篡改（M7-4 以服务端词库为准）
- 敏感密钥隔离（不暴露 ComfyUI/LLM/OSS 密钥）
- 文件魔数 Magic Bytes 校验防伪造后缀
- M8-2 审计台账全量中文留痕不可删改

### 7. 容错与状态机恢复 (10)
- GPU 主节点掉线自动降级至备用节点
- ComfyUI 仅返回 prompt_id 无有效文件 → 标记失败可重试
- 视频节点未配置/超时 → 诚实阻断不造假
- 断网重连与双击防重幂等保护
- 上游变更版本作废：已批准包回改 M7-1 标题或 M7-2 主图 → 旧审批自动失效强制重检
- 局部修改取消/500 失败不污染其余 4 张图
- M0-2 字段缺失兜底显示「待补（去 M0-2）」不报 undefined
- 刷新恢复持久层草稿与部分批处理失败单品重试

### 8. AI 专项测试 (8)
- 事实防幻觉与配件数量锁定（单支装不被竞品三件套带偏）
- 三层词库同名歧义人工复核机制（自有品牌不误杀、第三方商标必拦截）
- 合规改写建议准确度（Velcro→hook and loop / Waterproof→Water-resistant）
- EU_AI_Label 末端节点防裁剪丢失与双字段区分校验
- 结构化 Prompt（风格/视角/画幅/负向词/同步文案）一一映射
- 1+4 五图位构图差异化（白底/场景/卖点/尺寸/清单）
- 短视频 3 段分镜主体外观一致性
- Prompt 注入防御（输入忽略规则指令仍受合规前缀与规则引擎拦截）
