# CrossPilot · 商品内容创作与合规交付模块（M7）需求说明书

> **文档范围**：严格聚焦前端业务导航中的 4 个核心环节——**① 多语言商品文案（M7-1）**、**② 主图与详情套图（M7-2）**、**③ 商品短视频制作（M7-3，含 A+ 图文详情）**、**④ 合规检查与成品打包（M7-4）**。  
> **基线依据**：整合《CrossPilot-需求分析》《AI跨境电商平台V1.1-架构与需求》《AI跨境电商平台-模块需求细化_V1.1》《AI跨境电商平台V1.0-软件需求规格说明书》《AI跨境电商平台-两周开发计划与方案设计_V1.1》中与内容生产、ComfyUI 及上架合规相关的需求，并与已定型的 Web 原型（`docs/prototypes/web/`：`m7a`–`m7d`）逐项对齐。

## 1. 模块定位、上下游边界与业务原则

### 1.1 业务目标
将**已过审商品事实、品牌与平台合规规范、多语言 Listing 文案、1+4 电商套图、A+ 图文与 15 秒短视频、站点资质与元数据校验、主管审批与离线交付打包**串成一条可追溯、可局部修正、可阻断放行的闭环流水线，支持运营与内容团队在 1 个工作台内完成 `8 类核心上架资产 + 6 类扩展文案（8+N）` 的生产与上架前质检。

### 1.2 上下游接口契约（仅限本模块外部衔接）

| 方向 | 关联环节 | 传入 / 传出内容 | 约束规则 |
|---|---|---|---|
| **上游输入** | 选品终审（M4-3） | 主管已批准测款的新品清单（SKU、名称、类目、目标平台、审批人及理由） | 优先承接已批准测款新品；同步支持在售老品详情翻新 |
| **上游输入** | 商品主档（M0-2） | 品牌、材质、尺寸、功率、重量、颜色、控制方式、核心功能、售价/划线价、变体与库存 | 作为文案、套图、A+ 与买家视角预览的**唯一事实来源**，不可被模型虚构覆盖 |
| **上游输入** | 客服知识库（M1-2） | 同 SKU 或同品类高频 FAQ 与产品使用说明要点 | 在 M7-1 只读展示与引用，保障售前详情承诺与售后解答口径一致 |
| **下游交付** | 合规素材包导出 / 平台草稿对接 | 经主管签字批准的 `8+N` 离线合规素材包（HTML 归档或结构化资产包） | **绝不绕过人工确认直接改写线上在售店铺**；接入真实平台发布路径时须走「原生草稿 → 人工核对 → 分项回查」 |

### 1.3 四项核心产品原则（硬约束）
1. **双路径诚实声明**：文案阶段允许确定性内容策略与大模型润色并行，界面标明「AI」仅代表产品能力用语；图像与视频依赖外部工作流服务（如 ComfyUI），**只有取回真实且 MIME 校验通过的媒体字节后才记为成功**——仅拿到 `prompt_id` 任务号或服务未配置时，必须如实标示「演示图 / 处理中 / 失败阻断」，绝不产出空文件或伪造成功。
2. **主体事实锁定**：竞品参考仅学习构图与表达风格，**不得改变商品自身的外形、配件件数、材质参数或销售包装**（如单支装不可受竞品图影响生成三件套）。
3. **局部变更最小影响原则**：支持单段文案微调、单张图位重绘/局部精修、单段分镜画面或字幕重做；合格的其余素材保持不变，修改后只生成新版本并重新触发受影响项校验，不借用旧版本的审批结论。
4. **创作提示 ≠ 正式合规放行**：创作阶段的绿/红词条高亮仅作即时辅助提示；最终放行必须经过 M7-4 独立运行的合规检查记录（`ComplianceCheck`）与主管/审批人（`approver`）二次批准。

## 2. 四步协同流转与权限总览

### 2.1 四步接力链路与 `8+N` 交付体系
页面顶部提供贯穿 4 步的进度导航条（`M7-1 → M7-2 → M7-3 → M7-4`），实时汇总各步就绪度及整体交付进度（`0/8`～`8/8`），并支持「重置从第 1 步重走」以清空当前 SKU 的临时创作成果重新演练。

- **核心 8 类交付资产（计入主进度 `doneCnt/8`）**：
  1. 商品标题（M7-1）
  2. 五点卖点描述（M7-1）
  3. 商品详情描述（M7-1）
  4. 后台搜索词（M7-1）
  5. 商品主图 1（白底主图，M7-2）
  6. 4 张差异化详情附图（使用场景、核心卖点、尺寸规格、包装清单，M7-2）
  7. A+ 图文页面（M7-3）
  8. 商品种草短视频（15 秒，M7-3）
- **扩展 6 类上架文案（独立计数 `0/6`～`6/6`，构成 `8+N` 交付）**：
  - 使用说明与 FAQ、A+ 模块文案、规格变体命名、后台属性说明、图片 ALT 文本、认证与保修说明。

### 2.2 岗位权限矩阵（RBAC）

| 业务岗位 | M7-1 文案 | M7-2 套图 / 元数据 | M7-3 视频 / A+ | M7-4 合规检查 | M7-4 批准与导出 |
|---|---|---|---|---|---|
| **内容创作 / 审核人员（`creator`）** | 生成、扫描、选用、微调 | 编排、生成、重绘、写元数据 | 生成视频/分镜、生成 A+ | 发起合规检查 | **禁止自批**（仅可在主管批准后下载） |
| **主管 / 审批人（`approver`）** | 查看与修改 | 查看与修改 | 查看与修改 | 发起合规检查 | **批准发布包 + 解锁导出** |
| **大屏管理者 / 业务运营 / 选品员** | 只读查看 | 只读查看 | 只读查看 | 只读查看 | 禁止操作（越权点击记录 403 审计） |
| **BI / 仓管 / 客服 / 模拟买家** | 无权访问 | 无权访问 | 无权访问 | 无权访问 | 无权访问 |

### 3.1 M7-1：多语言商品文案（对应前端 `m7a`）

> **关联需求编号**：FR-09、FR-GC-01、FR-GC-04、FR-GC-05、CG-01～CG-04、KW-01～KW-04、QC-01

#### 3.1.1 输入与上游接力
1. **选品来源**：下拉分组列出「✓ M4 主管已同意测款（待上新创作）」与「在售老品详情翻新」商品；切换商品时重置创作工作区至 `0/8`，并展示商品缩略图、所属类目、审批来源标签及推荐理由。
2. **上游接力提示条**：顶部展示从 M0-2 主档自动带入的品牌、核心规格（如功率、重量）与目标平台规则库加载状态，并同步说明「第 1 步选定文案后将自动向 M7-2 与 M7-3 同步参考」。
3. **M1-2 客服知识库联动**：左侧卡片展示可复用的同 SKU / 同类目 FAQ 要点，避免详情页承诺与客服回答冲突。
4. **平台与语言配置**：
   - 目标上架平台：`亚马逊美国站`（标题上限 `200` 字符）、`虾皮泰国站`（上限 `120` 字符）、`TikTok 美区`（上限 `150` 字符）。
   - 输出语言：`English (US)` / `简体中文`（预留多语种扩展）。

#### 3.1.2 三层词库来源与实时合规扫描
1. **品牌用语规范（必用词）**：
   - 来源标注：`品牌词库 + SKU 卖点`。
   - 支持快捷词芯片一键追加（如 `USB-C`、`BPA-Free`、`Compact`、`CrossPilot`）。
   - 扫描规则：命中项在草稿预览与已选区中**绿底高亮**，统计 `已命中项数 / 总必用词数`。
2. **平台违禁词与三层联防提示（红线拦截）**：
   - 来源标注：`当前目标平台红线库`。
   - 除用户配置的平台违禁词外，规则引擎自动扫描三类风险：
     - **商标侵权词**（如 `Dyson`、`Ziploc`、`Velcro`、`Teflon`、`Thermos`）：命中直接拦截，提示合规改写词（如 `hook and loop`）。
     - **类目监管敏感词**（如 `FDA Approved`、`Sterilize`、`Cure`、`Medical Grade`、`Waterproof`）：命中直接拦截，提示替代词（如 `Water-resistant`）。
     - **格式与字节软提示**：检测连续 4 位及以上全大写单词（排除 `USBC`、`BPA`、`HDMI`、`LED` 等标准缩写）并给出黄色提醒；同步以 UTF-8 计算 `bytes` 长度（支持后台搜索词 `250 bytes` 限制核验）。

#### 3.1.3 文案生成、双语对照与就地微调闭环
1. **10 类文案页签结构**：
   - 第一行「核心 4 类交付文案」：`商品标题`、`五点描述`、`商品描述`、`后台搜索词`（带 `✓ / 待选` 状态徽标）。
   - 第二行「真实上架扩展 6 类文案」：`使用说明与FAQ`、`A+模块文案`、`规格变体命名`、`后台属性说明`（联动 M0-2 主档结构化字段）、`图片ALT文本`、`认证与保修说明`（带 `✓ / 可选` 状态徽标）。
2. **多版本生成与一键采纳**：
   - 点击「✨ 生成第 N 版多语言文案草稿」为当前商品生成多组差异化草稿（热搜词版、卖点版、场景版，含违禁词拦截测试样例）。
   - 含红线词或超过核心类目字符上限的草稿，操作按钮置红为「含违禁/超长(拦截)」，点击即弹出拦截提示并写入审计日志，**禁止写入交付清单**。
   - 提供顶部「⚡ 一键采纳 4 类核心文案」快捷动作，以及「🈶 显示/隐藏中文对照」全局开关。
3. **就地编辑微调与还原原稿**：
   - 任意页签写入交付清单后，下方展示当前已写入内容面板。
   - 支持点击 `✏️ 编辑微调` 展开英文正文与中文对照输入框；**输入过程中实时刷新品牌词命中、红线词命中与字符数**。
   - 点击 `💾 保存修改` 时再次执行红线词与超长强校验（不通过则阻断保存并记审计）；保存后标记「（已人工微调）」，并始终保留 `↩️ 还原 AI 原稿` 按钮（从 `m7SelectedOrigMap` 恢复初始 AI 采纳版本）。

### 3.2 M7-2：主图与详情套图（对应前端 `m7b`）

> **关联需求编号**：FR-10、FR-23～FR-32、FR-GC-06～FR-GC-10、QC-01～QC-03

#### 3.2.1 上游接力与主体锁定
1. **上游接力条**：显示当前锁定的产品参考图 SKU 与 M7-1 已选标题摘要；提供 `自动同步 M7-1 核心卖点至信息图` 开关，控制附图信息区是否自动带入第 1 步卖点文案。
2. **主体锁定约束**：明确标识「🔒 主体锁定」，所有出图与局部修改均以 M0-2 核定商品实物为主体参照，不得擅自增减配件或变更外观结构。

#### 3.2.2 结构化套图工作台
1. **配置参数（业务语言封装，避免要求运营手写底层英文 Prompt）**：
   - **套图工作流模板**：`标准白底主图 + 4张场景卖点附图模板`、`欧美居家生活方式高转化套图模板`。
   - **视觉风格**：`商业棚拍质感`、`自然居家日光`、`高对比卖点科技`。
   - **机位视角**：`正面平视`、`45° 立体俯拍`、`微距细节特写`。
   - **输出画幅比例**：`1:1 电商方图`、`3:4 竖版信息图`、`4:5 社媒首图`。
   - **负向避坑约束（可多选开关芯片）**：`禁止水印/促销角标`、`禁止乱码文字`、`禁止产品外观/Logo畸变`、`禁止杂乱背景反光`。
2. **1+4 差异化图位与独立要求编辑**：
   - 右侧采用 `1 大 + 4 小` 电商画廊布局，固定对应 5 个业务图位：
     1. **主图 1（白底正面）**
     2. **附图 2（使用场景）**
     3. **附图 3（核心卖点标注）**
     4. **附图 4（尺寸规格标尺）**
     5. **附图 5（包装清单展示）**
   - 点击任意图位即可切换选中态，左侧「当前图位设计要求」文本框按图位独立保存与修改，支持 `↺ 恢复推荐文案` 一键重置当前图位说明。

#### 3.2.3 三种生成与修改动作
1. **整套生成（1+4 一次性异步任务）**：展示分阶段任务进度（调度节点 → 渲染 5 张构图 → 写入合规元数据），支持幂等控制与真实文件 MIME（`image/*`）校验。
2. **单图位重绘**：点击 `🔄 仅重绘当前图位（保持其余 4 张不变）`，仅刷新选中图位并递增套图版本号，其余 4 张合格图片保持不动。
3. **局部修改（Inpaint 前后对比弹窗）**：点击 `✏️ 局部修改当前选中图位`，弹窗填写局部修改指令后执行局部重绘，提供**修改前原图 vs 修改后精修图**并排对比，确认后仅更新该图位状态并写入审计。

#### 3.2.4 可折叠 Prompt 编排与 ComfyUI 算力底座
1. **系统 Prompt 编排可视化（默认折叠）**：摘要栏展示当前结构化参数数量与「演示模拟」提示，点击「展开高级拼接细节」可核对系统如何将 `[平台合规前缀] + [模板风格] + [结构化参数] + [SKU 主体] + [图位要求] + [M7-1 同步卖点] --no [负向约束]` 拼接为 5 张图的生图参数。
2. **ComfyUI Server Pool 与工作流注册表**：
   - 展示各 GPU 节点名称、模型、版本、显存占用、队列长度与健康状态；节点掉线时自动停止派单并降级至健康节点。
   - 支持切换工作流注册表版本（记录 `workflow_id`、状态与所需显存，运行中任务锁定版本），展示多 SKU 批量作业队列、种子（`seed`）及单 SKU 独立状态（部分失败不影响已完成 SKU）。

#### 3.2.5 AI 人物图片合规元数据校验（IPTC / XMP）
1. **开关与前置约束**：通过「本套图包含 AI 合成模特/人物出镜」复选框声明是否触发人物合规校验。
2. **末端节点写入与双字段区分**：
   - 写入节点 `ComfyUI_EU_AI_Label` 必须位于工作流最末端，防止后续保存或转码覆盖元数据。
   - 明确区分并分别校验两个标记：`trainedAlgorithmicMedia`（AI 生成媒体标记）与 `contains-synthetic-performer`（合成人物声明）。
3. **最终文件读回校验与防裁剪丢失**：支持模拟「裁剪/转码导致元数据丢失」后立即触发阻断（状态置为未通过，拦截 M7-4 放行），必须通过「重新写入元数据并校验」对最终待发布文件读回验证通过后才恢复绿灯。

### 3.3 M7-3：商品短视频制作（对应前端 `m7c`，含 A+ 图文详情）

> **关联需求编号**：FR-11、FR-23～FR-29、FR-32、FR-GC-06～FR-GC-10、VD-01～VD-02

#### 3.3.1 上游接力与全局音画配置
1. **上游接力条**：实时统计 M7-2 已就绪图片数（`X/5`）与 M7-1 文案就绪情况，提示「支持分镜画面/运镜/字幕独立微调与单镜重做」。
2. **脚本风格与音画设置**：
   - 短视频脚本风格：`产品展示`、`开箱测评`、`场景种草`、`卖点快剪`。
   - 配音音色：`美式女声 · 亲和推荐`、`美式男声 · 专业测评`、`无配音 · 纯字幕节奏`。
   - 背景音乐：`轻快居家 Acoustic`、`科技极简电子感`、`无背景音 · 原声`。
3. **服务可用性诚实校验**：提供「模拟已配置视频服务」与「未配置视频生成节点（测试如实阻断报错）」切换；当视频节点未配置或 ComfyUI 未返回有效视频文件时，任务状态标记为失败并提示排查指引，**绝不以任务号替代成功交付**。

#### 3.3.2 15 秒竖屏短视频交互预览器与可编辑 3 段分镜
1. **竖屏成片预览器**：
   - 展示 `0–5s`、`5–10s`、`10–15s` 播放进度条、`▶ 播放 / ⏸ 暂停` 控制、当前分镜标签、运镜方式、配音/BGM 标签及双语字幕条。
2. **3 段可编辑分镜卡片（每段独立控制）**：
   - **分镜1（0–5s）**：痛点引入 / 开箱吸睛
   - **分镜2（5–10s）**：核心卖点实操
   - **分镜3（10–15s）**：品质清单与行动号召收尾
   - 每张分镜卡片支持以下交互：
     1. 点击分镜标题按钮立即跳转播放器至对应秒数（`0s` / `5s` / `10s`，按钮支持多行自动换行不溢出）。
     2. **画面来源选择**：下拉关联 M7-2 图位 1–5（主图或任一附图）。
     3. **运镜方式选择**：`微距慢推`、`平滑横移`、`稳态展示`、`轻缓拉远`。
     4. **双语字幕直改**：英文字幕与中文字幕输入框即时修改并同步至播放器字幕条。
     5. **`📥 引用 M7-1`**：一键从 M7-1 已选标题/五点描述（含中文对照）拉取对应文案填入当前分镜字幕；若 M7-1 尚未选定则给出明确提示。

3. **素材来源溯源与一致性校验**：
   - 下方实时汇总 `0-5s` / `5-10s` / `10-15s` 与 M7-2 图位及运镜的对应关系，并展示 3 段镜头主体外观一致性校验结果与分阶段执行日志。

#### 3.3.3 可视化 A+ 图文详情长页

## 6. 已确认的技术落地口径（V1 实施方案拍板）

> 针对当前「无真实卖家店铺、本地开发设备为普通笔记本、追求全链路真实闭环与可离线交付」的实际条件，第 6 节原待决事项已拍板锁定如下实现口径：

1. **三平台对接与本地离线导出（名义三平台 + 模拟商品 + 本地压缩包导出）**
   - **平台规则与数据**：名义接入 **Amazon 美国站、Shopee 泰国站、TikTok 美区**三套完整规则矩阵、字符/字节限制与合规模板；店铺与商品基础事实采用预置模拟数据（统一标注 `MOCK` 测试标识），**不申请或强连海外平台真实商家 API**。
   - **最终交付形态**：M7-4 主管批准后，由后端打包生成并下载**本地离线交付包**（支持 `.html` 可视化归档或 `.zip` 分目录压缩包：含平台模板 `listing_文案.csv`、`images/` 5 张真实套图、`aplus/` A+ 图文、`video/` 15 秒 `.mp4` 成片及合规校验报告），绝不直推线上店铺。

2. **文案 / 生图 / 视频生成引擎（云端 API + 本地 Pillow / FFmpeg 合成，不强依赖本地显卡 ComfyUI）**
   - **架构解耦**：后端通过统一适配器接口（`CopyGenerator` / `ImageGenerator` / `VideoGenerator`）提供生成能力，**普通笔记本无需部署本地 GPU ComfyUI**：
     - **文案与图像生成**：优先接入现成**云端大模型 API**（如阿里云通义千问 / 通义万相，或火山方舟豆包等按量付费接口），并内置 `Pillow` 本地图像加工兜底（完成白底/卖点标注/尺寸标尺/清单拼接并写入真实 `.png` 文件）。
     - **短视频生成**：支持两种模式协同——① 对接云端图生视频 API（如阿里云**通义万相图生视频** / 火山方舟**即梦/Seedance 视频 API**）生成动态镜头；② 由服务端 **`FFmpeg` 本地引擎**将 M7-2 套图 / 云端动态片段 + 运镜缩放动画 + 配音/BGM + 中英双语字幕合成为真实可播放的 15 秒 `.mp4` 文件。
     - **保留扩展性与诚实阻断**：接口协议保持与 ComfyUI 节点池注册表兼容（将来有 GPU 服务器可随时切换挂载）；同时保留「未配置生成节点时如实阻断报错」的校验分支，绝不造假文件。

3. **IPTC / XMP 合规元数据校验（本地真实文件读写闭环）**
   - **不接入海外平台审核接口**。
   - 后端在图片生成与保存的最末端，使用 Python（`Pillow` 写入 PNG 文本块 / EXIF / XMP）**真实将 `trainedAlgorithmicMedia` 与 `contains-synthetic-performer` 写入磁盘图片文件**。
   - M7-4 点击「运行上架合规检查」及模拟「裁剪转码丢失」时，后端**直接打开磁盘上的最终图片文件进行真实读回校验**——读不到即触发阻断，重新写入并通过读回后方准许放行。

4. **词库与规则维护权限（内置配置表 + 主管专属维护）**
   - **不单独建设庞大的规则中心后台**。
   - 三层词库（品牌词库、平台红线/商标/监管词库）与站点 × 类目合规规则矩阵以**数据库配置表 + 默认 JSON 种子数据**随系统初始化内置。
   - **权限边界**：仅授权 **`approver`（主管 / 审批人）** 岗位可增删改违禁词或对过期资质执行续期恢复，普通创作员 `creator` 仅只读使用、禁止自改红线规则；每次规则或资质变更自动写入不可篡改的中文审计台账。
