# CrossPilot · M7 商品内容创作与合规交付模块测试用例文档

> **测试范围**：严格对应导航栏中的 **4 个核心模块**——① 多语言商品文案（`m7a`）、② 主图与详情套图（`m7b`）、③ 商品短视频制作（`m7c`，含 A+ 图文长页）、④ 合规检查与成品打包（`m7d`）。  
> **对应依据**：《CrossPilot-M7商品内容创作与合规交付需求说明书》及当前 Web 前端实现（`docs/prototypes/web/crosspilot_standalone.html`、`pages_m7_m8.js`、`state.js`、`styles.css`）。

---

## 1. 测试前置条件与测试角色约定

### 1.1 测试入口与重置方法
- **运行入口**：打开 `docs/prototypes/web/crosspilot_standalone.html`（或部署后的前端路由 `#m7a`～`#m7d`）。
- **状态重置**：任意 M7 页面顶部流程条右侧均有 `🔄 重置从第1步重走` 按钮，可将当前选中 SKU 重置为 `0/8` 待创作初始状态，用于独立回归单条用例。
- **默认测试商品**：`SKU-00704 · 无线真空迷你封口机`（来自 M4 主管已同意测款清单，关联 M0-2 完整主档、变体价格及 M1-2 FAQ）。

### 1.2 涉及测试岗位（通过左上角「当前登录岗位」下拉切换）
| 岗位 Key | 页面显示名称 | 本模块权限边界 |
|---|---|---|
| `creator` | 内容创作 / 审核人员 | 可执行 M7-1/2/3 全部创作及 M7-4 发起合规检查，**不可主管批准发布包** |
| `approver` | 主管 / 审批人 | 拥有全部创作与合规检查权限，且**唯一有权批准发布包并解锁导出** |
| `planner` / `selector` / `manager` | 业务运营 / 选品研究员 / 管理者 | 仅只读查看，无权执行创作按钮、合规检查或审批操作 |
| `cs` / `warehouse` / `bi_analyst` | 客服 / 仓管 / BI | 无 M7 业务模块操作权限 |
