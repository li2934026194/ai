# CrossPilot · 智能选品与过会决策模块（M4）需求说明书

> **文档状态**：V1.0 正式基线（对齐《AI跨境电商平台-模块需求细化_V1.1》M01/M03、《SRS V1.0》DQ/SE/SO/PR/LG/IP 系列及原型 `docs/prototypes/web/pages_m4_m6.js`）
> **适用范围**：M4-1 候选商品导入（`m4a`）、M4-2 选品工作台与决策（`m4b`）、M4-3 测款终审拍板（`m4c`）

## 1. 模块定位、三方映射与核心原则

### 1.1 业务目标

M4 是 CrossPilot 的**售前选品漏斗与现金流安全阀**。规范候选新品从多源导入、成本利润试算、竞品与风险证据核对到主管终审过会的全流程，解决「外购估算当实盘毛利、漏算头程物流与 15% 平台佣金、展示四舍五入偷渡门槛、带商标/专利高风险拍脑袋投产、提交人自己批准过会」五大选品盲区。过会新品自动落入 M0 主档并打通 M7 内容制作。

### 1.2 三方编号对齐映射表

| 原型与现行路由 | 子模块名称 | 老师《模块需求细化 V1.1》对应 | 《SRS V1.0》需求编号 | 后端模块 / 前端视图 |
|---|---|---|---|---|
| `m4a` (`/m4/import`) | M4-1 候选商品导入 | M01 采集发现 + M03（历史复查与多源入池分诊） | DQ-01~05, SE-01~04 | `m4_selection` / `M4ImportView.vue` |
| `m4b` (`/m4/workbench`) | M4-2 选品工作台与决策 | M03（货源对照、物流与费用、毛利核算、商标专利） | SE-05~08, SO/PR/LG/IP | `m4_selection` / `M4WorkbenchView.vue` |
| `m4c` (`/m4/approval`) | M4-3 测款终审拍板 | M03（人工选中、事实版本锁定与交接 M4/M6） | SE-08 | `m4_selection` / `M4ApprovalView.vue` |

### 1.3 上下游接口契约

- **上游输入**：选品研究员导入的候选商品资料（或 1688/行业参考表）、M0-2 供应商比价参考与统一汇率。
- **下游输出**：
  - M4-3 批准（`APPROVED`）后自动写入或升级 `M0Product`（标记 `origin="M4_APPROVED"`、`approver`、`decision_reason`、`unit_cost_usd`、`sale_price_usd`）。
  - M7-1 `GET /m7/products/available` 即时将其置顶于「✓ M4 主管已同意测款（待上新创作）」分组，供文案/套图/视频接力。
  - M5-1 预测队列可同步读取已过会新品开启测款销量预测。

### 1.4 六项核心产品原则（硬约束）

1. **四源数据性质隔离与防演示混入**：严格区分「内部实盘选品」「外购行业估算」「平台热销公开」「仅演示数据」。文件带 `mock`/`demo`/`演示`/`测试` 字样却选择正式来源时拦截；外购估算品只作参考观察或「临时待核价」，不可直接批准投产。
2. **未舍入毛利精确比对门槛**：利润率计算保留小数精度（`round(..., 4)`），真实值 `29.996%` 面对 `30%` 门槛不可因展示四舍五入放行；缺失成本与运费时不填零，必须标明待核价。
3. **规格件数锁定与配件隔离**：配件报价不得混入整套商品成本；切换销售套装件数或修改规格时必须重新核价与重算物流/利润，保留历史记录。
4. **FBA 与 FBM 成本口径区分 & 物流周期红线**：FBM（单件拿货+头程+尾程+抽点，常规上限 30 天）与 FBA（拿货+海运+配送+抽点+仓储+10% 预留广告，常规上限 90 天）不可混算或靠隐瞒费用凑利润。
5. **侵权证据透明（模型分 ≠ 法律结论）**：商标命中或外观专利相似度评估仅作为证据呈交人工复核，禁止把未经校准的模型相似度直接等同于“保证不侵权”；检索失败不可宣称通过。
6. **测款终审职责分离（SoD）**：`selector` 提交待审后，必须由 `approver` 拍板；**提交人（`submitter_id`）绝对禁止自批（`403 M7-4032`）**。

## 3. 分页详细功能需求

### 3.1 M4-1：候选商品导入（`m4a` / `/m4/import`）

1. **单品录入与自动初算**：输入 SKU（自动转大写）、商品名称、类目、货源渠道、目标售价（USD > 0）、预估采购价（RMB > 0）、头程运费（RMB ≥ 0），入库即按统一公式自动算净毛利率与五维默认均分（`status="DISCOVERED"`）。
2. **V1.1 批量表格导入与分诊规划**：
   - 支持 CSV/Excel 上传并预览前 10 行；
   - 文件名含 `mock/demo/演示/测试` 而选正式来源时直接拦截报错；
   - 自动按「可投产（≥10% 毛利且非外购）」「临时待核价」「风险拦截」三类分诊统计入池。

### 3.2 M4-2：选品工作台与决策（`m4b` / `/m4/workbench`）

1. **左列候选清单与右列深度评估台**：实时调整目标售价、采购价、头程、五维评分（`demand`/`competition`/`margin`/`supply`/`compliance`）及选品运营建议（`operator_note`）。
2. **双状态提交按钮**：
   - 「保存评估」→ 重算毛利与总分，状态更新为 `EVALUATING`；
   - 「保存并提交审批」→ 状态锁定为 `PENDING_APPROVAL`，并记录 `submitter_id = actor.user_id`。
3. **V1.1 增强规划**：增加「只看可投产」过滤开关、2~4 款商品横向并排对比表、批量勾选送审与商标/专利风险证据字段。

### 3.3 M4-3：测款终审拍板（`m4c` / `/m4/approval`）

1. **待审队列呈现**：高亮毛利率是否满足硬门槛、五维综合分、提交人及推荐理由。
2. **硬门禁与审批**：
   - 审批意见（`note`）非空必填；
   - `submitter_id == actor.user_id` 强制抛出 `403 M7-4032`；
   - 同意测款（`APPROVED`）时在同一事务内创建/更新 `M0Product`，并可选择联动触发 M7 首版草稿任务（V1.1 补齐可选自动触发开关）；
   - 驳回（`REJECTED`）保留历史评语与原值，不写入 M0 主档。

## 5. 非功能需求与验收标准

### 5.1 性能、准确率与审计覆盖率

1. **接口响应基准**：单品导入与重算保存 P95 ≤ 80ms；候选池查询 P95 ≤ 100ms；终审拍板原子交接写 `m4_candidates` + `m0_products` + `core_audit_events` P95 ≤ 120ms。
2. **数值精度**：毛利率保留 4 位小数（`round(..., 4)`）以防止四舍五入偷渡门槛；权重五维评分精确加和 `1.0`。
3. **审计完整性**：候选入池、评估、送审、同意/驳回 100% 留存中文审计句。

### 5.2 核心验收标准矩阵（M4-AC-01 ~ M4-AC-06，对齐 M03-A01~A11）

| 验收编号 | 对应老师用例 | 给定条件与动作 | 通过标准 |
|---|---|---|---|
| **M4-AC-01** | M03-A04/06 | 录入 `target_price_usd=29.99, est_cost_rmb=42, est_shipping_rmb=18` | 精确算出净毛利率，不因展示四舍五入绕过门槛（如 `29.996% < 30%` 不可自动放行） |
| **M4-AC-02** | M03-A02/11 | 选品单品评估暂存 `EVALUATING`，随后提交送审 `PENDING_APPROVAL` | 状态按序流转，锁定 `submitter_id` 与操作审计 |
| **M4-AC-03** | — | `selector` 自批或 `approver` 自提自审调用 `/decide` | 返回 `403 M7-4031` / `403 M7-4032` 拦截 |
| **M4-AC-04** | M03-A09/10 | 未完成核价或含风险证据候选品 | 不允许静默通过，保留待确认或人工裁定依据 |
| **M4-AC-05** | E2E-01 | `approver` 批准某候选新品后检查 M0 与 M7 | `GET /m0/products` 与 `GET /m7/products/available` 立即查见该 SKU 且 `origin="M4_APPROVED"` |
| **M4-AC-06** | — | `org_other` 访问或无权限角色（`creator`/`cs`/`warehouse`）访问 M4 | 返回 `403`，租户与 RBAC 隔离严密 |

## 6. 已确认的技术落地口径（V1 实施方案拍板）

1. **V1 固定费用基准**：V1 统一使用 15% 平台佣金、汇率 `7.2` 进行初始净毛利测算，同时保留五维评分与运营批注；不依赖外部付费侵权 API 密钥。
2. **V1.1 精修规划**：补齐批量表格导入与前 10 行预览、测试文件名拦截、多选并排对比以及终审通过后可选一键自动创建 M7 首版文案草稿。
