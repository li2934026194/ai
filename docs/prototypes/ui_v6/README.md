# CrossPilot UI 原型图总览（对齐老师原型布局 · 多页按钮拆分 · 全注释台账版）

本目录收录 **M0 公共底座 + M1~M7 七大 Agent 模块共 18 张**低拥挤度分屏 UI 原型图。  
严格遵循老师原型设计风格与您的布局要求：**拒绝单页堆砌**，通过顶部显式 **「页面切换按钮」** 将复杂流程拆分为独立专注的子页面（例如 M7 明确拆出 **Listing 文案页 / ComfyUI 主图页 / ComfyUI 短视频与合规页**；M1 拆出 **客服三栏工作台 / 推荐商品库 / 售后工单审批**；M4 体现 **`planner` 初筛进待选清单 → `approver` 最终测款拍板**），且**每张页面均保留右侧「1→2→3 功能块 · SRS 出处 · 技术支撑」注释栏与底部「文字/数字来源台账」**。
