# 严格业务风控、9角色权限矩阵与全链路契约设计（V3 · P0/P1/P2 完善版）

> 对应流程图目录：`docs/prototypes/modules/`（共 **16 张 PNG**：`m00_rbac_matrix.png` + `m01_shop.png` ~ `m13_kb.png` + `m14_ux_principles.png` + `m15_cross_module_contract.png`）  
> 核心原则：**消除灰区（全显式 `DENY`）、剥离管理员业务权、Owner 防瓶颈、全链路 `fact_signature` 契约、SHA-256 哈希链审计、危险操作统一 30 秒撤回、P0 阻断必须先于 P1/P2 落地**。

---

## 一、改进优先级地图（P0 → P1 → P2）

1. **P0 阻断级（必须现在补齐，严禁带病上线）**：
   - 权限矩阵修复：Owner 防瓶颈（财务/合规仅保留「阅+争议裁决」）；Admin 剥离所有业务板块操作权（`01~11, 13` 显式 `DENY`，仅留 `12 系统管理`）；消灭空白灰区全部显式 `DENY`；Auditor 明确赋予全量审计日志只读。
   - 订单金额字段库级只读，任何修改必须走「金额变更申请单」。
   - 销量预测每周一冻结，历史值禁改；**`WAPE > 30%` 硬拦截禁止直转自动补货**。
   - 上传知识库强制扫 PII/底价及 **Excel 隐藏列**，未 `PUBLISHED` 禁止 AI 引用，**过期政策自动下架** + 影响问答预览。
   - 补全跨板块 `fact_signature` 契约（覆盖 `8→9→4→2→3` 每个交接点）+ 补全异常闭环（审批驳回退回发起人 / 库存中途变动拦截重算）。
   - 板块 12 审计日志升级为 **Append-Only + SHA-256 哈希链防篡改**。
   - 专设板块 10「经营总览」老板一屏晨会视图（汇总 `8预测+9补货+3财务+2订单+7客服`）。
2. **P1 体验级（顺手度提升）**：
   - Auto-Fill 必标「来源 + 可编辑」；拦截明示「违反哪条规则 + 怎么改 + 一键跳转」。
   - 危险操作（退款 / 内容发布 / 商品改价 / 客服发送 / 补货提交）统一 **30 秒撤回窗口**。
   - 店铺失败重试 3 次指数退避转人工单 + SLA 超时逐级通知；财务按结算日锁汇率、CostCard Diff 高亮；选品模板下载 + 异常列高亮 + 评分权重模板保存；内容 5 秒存稿 + `bilingual` 一键采纳 + 红线高亮一键替换；客服近 3 单 + 设备 + PII 脱敏 + 快捷回复；知识库审前「模拟买家试问盒」。
3. **P2 增强级（长期建设）**：
   - 移动端审批、数据埋点看板、AI 意图识别置信度展示、评分模板市场、多情景仿真沙箱演练、跨板块日志关联查询、规则变更影响分析、多语言/多时区深度适配。

## 二、企业级 9 角色权限矩阵（P0 修复版 · 见 `m00_rbac_matrix.png`）

| 岗位角色 | 定位 | 核心权限边界 | 严禁越权与三权分立隔离 |
|---|---|---|---|
| **1. 老板 (`owner`)** | 关键决策 + 异常裁决 | 关键节点拍板（店铺解绑/大额补货 `$30w+`/大额异常退款/高敏授权二级复核）；一屏晨会只读全盘 | **防瓶颈 & 三权分立**：在 `03 财务利润`、`06 内容`、`13 知识库` **仅保留「阅 + 争议裁决」**，不插手日常审批 |
| **2. 财务 (`finance`)** | 钱袋子与账务主责 | 日常费用导入、`CostCard` 编审锁版、汇率锁算、月结核算；审批订单退款、选品利润、`$3k~$30w` 补货会签 | 无权操作内容、客服对话、预测修改、系统管理（全部显式 `DENY`） |
| **3. 运营主管 (`ops_manager`)** | 日常业务审批 | 审批小额退款/订单跳态、商品改价停售、选品常规测款、内容发布、预测手修、`≤$3k` 补货 | **禁止自提自批（SoD）**；`03 财务`、`12 系统管理` 显式 `DENY` |
| **4. 运营专员 (`operator`)** | 日常运营提交 | 商品维护、选品导入提审、内容草稿生成、预测提交、补货提交、`13 知识库` 草稿上传 | **严禁自批**；`03 财务`、`07 客服`、`12 系统` 显式 `DENY` |
| **5. 采购仓配 (`warehouse_buyer`)** | 货流与三单收货 | 维护库存盘点单、按审批生成锁定数量 PO、三单匹配收货质检（不合格品进隔离区） | 禁止修改审批后 PO 数量；`03 财务`、`05~07`、`12~13` 显式 `DENY` |
| **6. 客服 (`cs_agent`)** | 买家沟通与工单 | 脱敏查近 3 单+设备、AI 辅助翻译(`bilingual` 一键采纳)与回复、建售后补偿申请、传 KB 草稿 | 命中四类红线强制切人工；`03/05/06/08/09/12` 显式 `DENY` |
| **7. 合规 (`compliance`)** | 规则与法务红线 | 选品合规一票否决；主责维护内容规则库（版本化/双人生效/回滚/软删）与审发 `13 知识库` | `02/03/08/09/12` 显式 `DENY` |
| **8. 系统管理员 (`sys_admin`)** | 纯技术账号配置 | **仅在 `12 系统管理` 配账号与权限模板**；超最小权限模板须二级审批；离职二次复核秒失效 | **彻底剥离业务权**：`01~11`、`13` **全部显式 `DENY`**，禁碰店铺/订单/财务 |
| **9. 审计员 (`auditor`)** | 全量独立监督 | **全系统 13 板块 + `12.4` 哈希链审计日志全量只读** | 全系统零写权限 |

## 三、全链路契约与逐板块 P0/P1 核心清单（对应 `m01~m15`）

- **全链路契约（`m15_cross_module_contract.png`）**：`fact_signature = SHA256(org_id | shop_id | sku_ver | cost_card_ver | sales_cutoff_ts | inv_snapshot_id | forecast_run_id)` 贯通 `2订单 → 3财务 → 4商品 → 8预测 → 9补货 → 10总览`。任一上游变动即拒绝旧批并退回重算，驳回必须填理由退回发起人待办。
- **1 店铺（`m01_shop.png`）**：OAuth scope 越权直接拒+留痕；`org_id` 责任书 1 对 1 硬校验、解绑二次审批；同步失败重试 3 次指数退避转人工单；SLA 超 1h 逐级通知。
- **2 订单（`m02_order.png`）**：`order_id+平台` 去重；金额库级只读必须走变更申请单；状态机跳态须审批；退款分级+退回填因+30 秒撤回。
- **3 财务（`m03_finance.png`）**：结算日锁汇率超波动冻结重算；`CostCard` Diff 高亮+缺项禁核算；月结后仅走红字调整单+老板批+哈希存证；负毛利标红附疑似原因。
- **4 商品（`m04_product.png`）**：一码多物/重复 ASIN 实时拦截；保本价硬校验+成本变动重算通知；改价停售先展受影响订单库存；四态分列且缺 PO 在途禁转可售。
- **5 选品（`m05_selection.png`）**：字段映射模板化+异常列高亮+正确模板下载；五条件逐条显因、合规不过禁选；权重可存模板；测款 `≤$25/款` 硬上限；10 天出单异常高亮+一键复盘报告。
- **6 内容（`m06_content.png`）**：5 秒自动存稿+`bilingual` 一键采纳；红线命中 `BLOCKED`+高亮一键替换（不可跳过）；三状态机+高风险送合规+30 秒撤回；规则库版本化双人确认+回滚+软删。
- **7 客服（`m07_cs.png`）**：负面/退款自动升级；查单带近 3 单+设备+PII 脱敏；四类命中转人工；30 秒撤回+补偿分级审批。
- **8 预测（`m08_forecast.png`）**：不完备直拒明示缺啥；WAPE 展示+算法切换；手修必填理由+影响预览；每周一冻结历史禁改+**`WAPE>30%` 硬拦截禁自动补货**。
- **9 补货（`m09_replenish.png`）**：全链路 `fact_signature` 校验+显示货期；三方比价到仓天数+风险量；三档审批（`≤$3k` 主管 / `>$3k~$30w` 财务 / `$30w+` 老板），期间变数退回重算；PO 锁数量；三单匹配上架坏品隔离。
- **10 总览（`m10_dashboard.png`）**：汇总 `8+9+3+2+7` 老板一屏晨会视图；核验签名与 SLA；按角色裁剪脱敏；红灯一键跳转。
- **11 问数（`m11_qa.png`）**：写库/改价/删记录直拒；SQL 生成前注入 RBAC；只读沙箱禁直连生产库+空数据/跨表校验；数字附来源表+口径+导出+常用问题芯片。
- **12 系统（`m12_rbac.png`）**：9 岗最小权限超范围二级审批；离职二次复核秒失效+到期自动回收；每次实时查库非缓存；**Append-Only + SHA-256 哈希链防篡改**。
- **13 知识库（`m13_kb.png`）**：PII/底价脱敏（**含扫描表格隐藏列**）；生效范围与可视化预览；审前模拟买家试问、未 `PUBLISHED` 禁引用；**过期政策自动下架+影响问答预览**。
